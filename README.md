# Expense Tracker

A personal finance tracker with interactive charts, built with React and TypeScript.

## Features
- Track income and expenses with categories
- Pie chart breakdown by expense category
- Monthly bar chart overview (income vs expenses)
- Balance, total income, and total expenses summary cards
- Filter transactions by type
- Persists to localStorage

## Tech Stack
React 18 · TypeScript · Tailwind CSS v4 · Recharts · Vite

## Getting Started
```bash
npm install
npm run dev
```
